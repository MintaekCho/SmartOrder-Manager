# 크롤링 대안 방안

## 현재 상황
- 도매꾹, 네이버쇼핑 등 주요 사이트들이 봇 탐지로 크롤링 차단
- Playwright headless 브라우저가 감지됨

## 대안 1: 공식 API 사용 (권장)

### 네이버 커머스 API
- https://developer.naver.com/docs/common/
- 스마트스토어 판매자용 API 제공
- 상품 정보 조회 가능

### 쿠팡 파트너스 API
- https://partners.coupang.com/
- 상품 검색 및 정보 조회 API 제공

### 도매꾹 API
- 도매꾹은 공식 API를 제공하지 않음
- 판매자 회원 가입 후 대량 상품 데이터 다운로드 기능 활용

## 대안 2: 수동 데이터 입력 + 자동화

현재 구현된 UI를 활용:
1. 도매처에서 수동으로 상품 정보 복사
2. 자동화 페이지에서 상품 정보 입력
3. 상세페이지 자동 생성
4. 쿠팡 등록 자동화

## 대안 3: 브라우저 확장 프로그램

Chrome 확장 프로그램을 만들어서:
1. 사용자가 도매처 페이지 방문
2. 확장 프로그램이 상품 정보 추출
3. 우리 시스템으로 데이터 전송

## 대안 4: Stealth 플러그인 사용 (위험)

```bash
npm install puppeteer-extra puppeteer-extra-plugin-stealth
```

- 봇 탐지 우회 시도
- 사이트 이용약관 위반 가능성
- IP 차단 위험

## 대안 5: 프록시 서비스 사용 (비용)

- Residential Proxy 서비스 사용
- 월 $50~$500 비용
- Bright Data, Oxylabs 등

## 권장 접근법

### 개발/테스트 단계
- Mock 데이터 사용 (현재 구현됨)
- 실제 크롤링 없이 전체 플로우 테스트

### 운영 단계
1. 도매꾹 판매자 가입 → 상품 데이터 대량 다운로드
2. CSV/Excel 업로드 기능 구현
3. 상세페이지 이미지는 도매처에서 수동 다운로드 후 업로드
4. 쿠팡 Wing API로 자동 등록

## 다음 단계 구현 제안

1. **CSV 업로드 기능**: 도매처에서 다운로드한 상품 데이터 일괄 업로드
2. **이미지 URL 입력**: 상세페이지 이미지 URL 직접 입력
3. **상품 정보 수동 입력 폼**: 크롤링 없이 직접 입력
