# 통합 판매 관리 시스템

> 쿠팡 셀러를 위한 상품 관리 및 자사몰 운영 통합 솔루션

## 프로젝트 개요

농산물 유통 사업자를 위한 **쿠팡 Wing API 연동 관리 시스템**과 **자사몰**을 통합 개발한 프로젝트입니다.
상품 등록부터 주문 관리, AI 기반 썸네일 생성까지 셀러 운영에 필요한 기능을 제공합니다.

## 주요 기능

### 🛒 쿠팡 Wing API 연동
- 상품 등록/수정/삭제 자동화
- 실시간 주문 조회 및 상태 관리
- 판매 통계 대시보드

### 🎨 AI 썸네일 생성
- Google Gemini API 활용
- 상품명 기반 자동 디자인 생성
- 다양한 템플릿 제공

### 📊 시세 분석
- KAMIS API 연동 (농산물 유통정보)
- 네이버 데이터랩 검색량 분석
- 가격 추이 시각화

### 🏪 자사몰 (싱이음몰)
- 상품 카탈로그 및 상세페이지
- 장바구니, 찜하기 기능
- 카카오 소셜 로그인
- 주문/결제 시스템 (토스페이먼츠)

---

## 기술 스택

| 구분 | 기술 |
|------|------|
| **Frontend** | Next.js 16, React 19, TypeScript, Tailwind CSS |
| **Backend** | Next.js API Routes, Prisma ORM |
| **Database** | PostgreSQL (로컬) / Supabase (배포) |
| **Storage** | Supabase Storage |
| **AI** | Google Gemini API |
| **External API** | 쿠팡 Wing API, KAMIS API, 네이버 데이터랩 |
| **Auth** | NextAuth.js (카카오 로그인) |
| **Payment** | 토스페이먼츠 |

## 화면 구성

### 관리자 시스템
- **대시보드**: 주문 현황, 판매 통계, 알림
- **상품 관리**: 상품 CRUD, 쿠팡 연동
- **주문 관리**: 주문 조회, 상태 변경
- **도구**: AI 썸네일 생성, 시세 분석

### 자사몰
- **메인**: 추천 상품, 신상품
- **상품 목록/상세**: 카테고리별 조회
- **마이페이지**: 주문내역, 찜목록, 리뷰

## 성과 및 특징

- **API 연동 자동화**로 상품 등록 시간 80% 단축
- **AI 썸네일**로 디자인 외주 비용 절감
- **통합 시스템**으로 멀티 채널 운영 효율화
- **실시간 시세 분석**으로 가격 경쟁력 확보
