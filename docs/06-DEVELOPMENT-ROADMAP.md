## Phase 0: 사전 준비 (개발 전)

### 필수 준비사항

| 항목 | 상세 | 비고 |
|-----|-----|-----|
| 사업자 등록 | 개인/법인 사업자 등록 | 쿠팡 Wing 필수 |
| 통신판매업 신고 | 관할 구청 신고 | 온라인 판매 필수 |
| 쿠팡 Wing 가입 | 판매자 등록 및 승인 | API 키 발급 |
| 도매처 가입 | 도매꾹, 도매매 등 | 최소 1곳 |
| 사업용 계좌 | 정산 수령용 | 권장 |

### 쿠팡 Wing API 준비
1. 쿠팡 Wing 로그인
2. 개발자 센터 → API 사용 신청
3. Access Key, Secret Key 발급
4. Vendor ID 확인

## 시작하기

### Quick Start

```bash
# 1. 레포지토리 클론 (나중에)
git clone <repo-url>
cd coupang-automation

# 2. 의존성 설치
pnpm install

# 3. 환경 변수 설정
cp .env.example .env.local
# .env.local 편집

# 4. 데이터베이스 시작
docker-compose up -d

# 5. 마이그레이션 실행
pnpm prisma migrate dev

# 6. 개발 서버 시작
pnpm dev
```
