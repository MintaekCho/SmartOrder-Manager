# 쿠팡 위탁판매 자동화 시스템

## 프로젝트 개요

### 목적
쿠팡 Wing을 통한 위탁판매 사업의 전 과정을 자동화하여 효율적인 운영과 수익 극대화를 달성한다.

### 핵심 기능
1. **상품 분석**: 도매처 인기상품 분석 및 수익성 예측
2. **상품 등록**: 쿠팡 Wing API를 통한 자동 상품 등록
3. **주문 관리**: 주문 감지 → 도매처 발주 → 송장 입력 자동화
4. **모니터링**: 실시간 매출/마진 대시보드

---

## 시스템 요구사항

### 기능적 요구사항

#### FR-001: 상품 분석
- 도매처 인기상품 크롤링 (도매꾹, 도매매, 오너클랜 등)
- 쿠팡 경쟁상품 가격/리뷰 수집
- 마진율 자동 계산 (도매가, 쿠팡 수수료, 배송비 고려)
- 유망 상품 점수화 및 추천

#### FR-002: 상품 등록
- 도매처 상품정보 파싱 및 변환
- 이미지 다운로드 및 최적화
- 쿠팡 Wing API 연동 대량 등록
- 카테고리 자동 매칭
- 가격 정책 설정 (마진율 기반)

#### FR-003: 주문-발주 자동화
- 쿠팡 신규 주문 실시간 감지
- 도매처 자동 발주 (가능한 경우)
- 수동 발주 시 알림 및 가이드
- 송장번호 수집 및 쿠팡 자동 입력
- 배송 상태 추적

#### FR-004: 모니터링 대시보드
- 오늘/주간/월간 매출 현황
- 상품별 판매량 및 마진 분석
- 미처리 주문 알림
- 품절/재고 경고
- 가격 변동 감지

### 비기능적 요구사항

| 항목 | 요구사항 |
|-----|---------|
| 성능 | 대시보드 로딩 3초 이내 |
| 가용성 | 99% 이상 (주문 감지 크리티컬) |
| 보안 | API 키 암호화 저장, HTTPS 필수 |
| 확장성 | 다중 도매처 지원 구조 |

## 사용자 스토리

### US-001: 상품 리서치
```
AS A 위탁판매자
I WANT TO 도매처 인기상품과 쿠팡 경쟁상황을 한눈에 보고 싶다
SO THAT 수익성 있는 상품을 빠르게 찾을 수 있다
```

### US-002: 상품 등록
```
AS A 위탁판매자
I WANT TO 선택한 상품을 자동으로 쿠팡에 등록하고 싶다
SO THAT 수작업 시간을 줄이고 더 많은 상품을 운영할 수 있다
```

### US-003: 주문 처리
```
AS A 위탁판매자
I WANT TO 주문이 들어오면 자동으로 발주가 되길 원한다
SO THAT 24시간 주문 처리가 가능하다
```

### US-004: 현황 모니터링
```
AS A 위탁판매자
I WANT TO 매출과 마진을 실시간으로 확인하고 싶다
SO THAT 사업 현황을 파악하고 의사결정을 할 수 있다
```

## 제약사항

### 법적 제약
- 쿠팡 Wing API 이용약관 준수
- 도매처 크롤링 시 robots.txt 확인
- 개인정보보호법 준수 (고객 정보 처리)

### 기술적 제약
- 쿠팡 Wing API 호출 제한 (Rate Limit)
- 도매처별 상이한 데이터 구조
- 일부 도매처 자동 발주 불가

### 사업적 제약
- 사업자 등록 필요 (쿠팡 Wing 이용 조건)
- 도매처 회원가입 및 승인 필요
- 초기 운영자금 필요 (발주 선결제)

## 용어 정의

| 용어 | 설명 |
|-----|-----|
| 쿠팡 Wing | 쿠팡 판매자 센터 (마켓플레이스) |
| 위탁판매 | 재고 없이 주문 발생 시 도매처에서 직배송 |
| 마진율 | (판매가 - 도매가 - 수수료 - 배송비) / 판매가 × 100 |
| 도매처 | 도매꾹, 도매매, 오너클랜 등 도매 플랫폼 |
